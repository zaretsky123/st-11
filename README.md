# Расписание СТ-11

Одностраничное расписание второй подгруппы СТ-11. Опубликовано через GitHub Pages:
<https://zaretsky123.github.io/st-11/>.

## Автоматическое обновление

Каждый день в 06:17 по московскому времени workflow
`.github/workflows/update-schedule.yml` запускает `scripts/update_schedule.py`.
Он также проверяется автоматически при изменении самого парсера или workflow.
Скрипт получает нечётную и чётную недели с официальной страницы МГТУ,
выбирает вторую подгруппу, проверяет результат и обновляет
`schedule-data.js` только при реальном изменении расписания.

Если сайт МГТУ недоступен или структура страницы стала неожиданной, workflow
завершается с ошибкой до публикации. Последняя корректная версия расписания
остаётся на сайте.

## Постоянные правила СТ-11

- используются занятия второй подгруппы;
- география и родная литература не добавляются;
- занятие «Русский язык вместо иностранного языка (для иностранных граждан)» не добавляется;
- лекция по биологии в нечётную пятницу показывается первой парой;
- семестр начинается 1 сентября 2026 года и длится 17 учебных недель — этот период задаётся в интерфейсе сайта.

Запустить обновление вручную можно на вкладке **Actions** →
**Обновление расписания СТ-11** → **Run workflow**.
